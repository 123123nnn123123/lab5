Запуск сервера
node main.js -h 127.0.0.1 -p 3000 -c ./cache

1. GET: перший запит, картинки в кеші немає очікується 200, Content-Type: image/jpeg, X-Cache: MISS
curl -D - -o out.jpg http://127.0.0.1:3000/404

2. GET: повторний запит, картинка береться з кешу очікується 200, X-Cache: HIT
curl -D - -o out.jpg http://127.0.0.1:3000/404

3. Завантаження власної картинки для PUT
curl -o cat.jpg https://http.cat/418

4. PUT: запис власної картинки в кеш під кодом 404 
curl -i -X PUT --data-binary @cat.jpg http://127.0.0.1:3000/404

5. GET після PUT: має повернутися картинка 418, а не 404 
curl -D - -o after_put.jpg http://127.0.0.1:3000/404

6. PUT з порожнім тілом очікується 400
curl -i -X PUT http://127.0.0.1:3000/404

7. DELETE: видалення картинки з кешу очікується 200
curl -i -X DELETE http://127.0.0.1:3000/404

8. DELETE: повторне видалення, файлу вже немає очікується 404
curl -i -X DELETE http://127.0.0.1:3000/404

9. GET неіснуючого коду очікується 404, у кеш нічого не зберігається
curl -i http://127.0.0.1:3000/999

10. GET за некоректним шляхом очікується 404
curl -i http://127.0.0.1:3000/abc

11. Недозволений метод POST очікується 405 і заголовок Allow: GET, PUT, DELETE
curl -i -X POST http://127.0.0.1:3000/404

12. Недозволений метод PATCH очікується 405
curl -i -X PATCH http://127.0.0.1:3000/404
